# Sena Academy — Cinematic Video Storyboard Prompts

These prompts are structured for Higgsfield Seedance 2.0. They use timestamped cuts (cuts at 4s and 10s) to generate a complete, continuous 15-second cinematic sequence in one prompt.

---

## Storyboard 1: "The Cloud Coding Solution" (Objection: Laptop Specs)
*   **Goal**: Show that you don't need a powerful laptop to build web and mobile apps because Sena Academy teaches cloud-hosted coding setups.
*   **Talent**: Kofi (`@kofi`) in Cozy Accra Desk (`@accra_night_desk`)

### Prompt to Save as `scratch/prompt-laptop.txt`:
```
[VIDEO TYPE: Cinematic action. 15-second vertical tech B-roll sequence.]

[CAMERA DIRECTION & ANGLE:
* 00:00 - 00:04: Macro slow pan across a basic older grey Windows laptop keyboard as hands type.
* 00:04 - 00:10: Slow push in over Kofi's shoulder showing a minimalist glowing browser window with VS Code running in the cloud.
* 00:10 - 00:15: Low angle close-up of Kofi's face as he looks at the screen, smiling in relief and nodding with confidence.]

[SUBJECT: Kofi, a 22-year-old Ghanaian developer, neat dreadlocks tied back, wearing a black oversized hoodie, focused expression.]
[VISUAL ACTION: 
* 00:00 - 00:04: Kofi is typing rhythmically on the keyboard. 
* 00:04 - 00:10: Code is scrolling smoothly inside a web browser container, compiling a Next.js application.
* 00:10 - 00:15: Kofi leans back slightly, relaxed, looking at the glowing screen with pride.]
[ENVIRONMENT: A dark wood study desk in a cozy Accra bedroom at night, warm desk lamp lighting, window showing soft streetlights.]
[COLOUR TONE: Rich warm amber backlight contrasted with cool blue screen light on his face.]
[LIGHTING AND MOOD: Atmospheric, cinematic shadow, high contrast.]
[SFX: Rapid mechanical keyboard keyclicks, a soft sigh of relief, faint ambient laptop fan hum. No music.]
```
