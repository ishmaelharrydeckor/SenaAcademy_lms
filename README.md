# Sena Academy — Online Learning Management System (LMS)

A full-stack, scalable online learning management system built for delivering courses, managing student enrollments, and tracking learning progress.

🌐 **Live Demo:** [https://lms-fdqzg2r77-deckorharry-s-projects1.vercel.app](https://lms-fdqzg2r77-deckorharry-s-projects1.vercel.app)

---

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router, React, TypeScript)
- **Styling**: Tailwind CSS
- **Database & Auth**: Supabase (PostgreSQL + Row-Level Security + Storage)
- **Deployment**: Vercel

---

## ✨ Features

- **Authentication & Security**: Secure user signup/login using Supabase Auth with Row-Level Security (RLS) policies.
- **Course Management**: Dynamic course modules, video lesson delivery, and student progress tracking.
- **Responsive Interface**: Custom mobile-first design with drawer navigation for seamless learning across mobile and desktop devices.
- **Performance**: Optimized page load speeds with sub-2s initial render and dynamic content caching.
