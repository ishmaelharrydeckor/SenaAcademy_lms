# Video Hooks & Retention Framework (Made to Stick, Hooked, Blink)

This rulebook trains the **Creative Research Agent** (to evaluate hooks in viral videos) and the **Script Writer** (to construct attention-grabbing intros and hold retention).

---

## 1. The First 3 Seconds (Blink Strategy)

Viewers make split-second decisions to swipe away. Intros must avoid greetings (*"Hey guys, welcome back..."*) and immediately execute a **Pattern Interrupt**:

### A. High-Velocity Opening Hook Types
1.  **The Counter-Intuitive Truth**: Break their expectation.
    - *Example*: *"Stop learning Python in 2026. Here's what you should build instead."*
2.  **The Accusation Hook**: Speak directly to their current bad habits.
    - *Example*: *"You're stuck in tutorial hell because you're copying code instead of building things."*
3.  **The Visual First Frame**: Start with a high-value visual cue.
    - *Action*: Show a running terminal compiling, a live interactive dashboard, or a 3D interface spinning, before panning to the speaker.

### B. Visual & Auditory Pattern Interrupts
- The script must dictate visual changes (zooms, text overlays, sound effects) every **2.5 to 3 seconds** to prevent brain fatigue and swipes.

---

## 2. Structural Stickiness (The SUCCES Model)

To make a concept stick in the viewer's memory, apply the Heath Brothers' **SUCCES** rules:

*   **Simple**: Keep the script focused on ONE core concept (e.g. *what is an API?*). Do not explain the history of the web.
*   **Unexpected**: Pose a mystery at the start. Open a curiosity loop and delay the resolution.
    - *Example*: *"I built a WhatsApp bot in 4 hours using this simple library, but it crashed on user #10. Here is the single line of code that saved it."*
*   **Concrete**: Use real, tactile examples. Talk about code files, databases, pricing models, and laptop keyboards. Do not use abstract terms.
*   **Credible**: Show, don't tell. Show the code running, show terminal errors, show GitHub green squares.
*   **Emotional**: Appeal to their pride, frustration, and desire for independence.
    - *Frustration*: *"Spending 3 hours fixing a trailing comma is exhausting."*
    - *Independence*: *"Build projects that run while you sleep."*
*   **Stories**: People remember stories, not instructions. Frame scripts around:
    - *The Bug Search*: Trying to fix a bug late at night.
    - *The Builder's Journey*: Starting from scratch and launching.

---

## 3. The Hooked Loop (Engagement Cycle)

Ensure your scripts create a micro-habit loop for the viewer:

1.  **Trigger (Internal/External)**: Focus on their internal trigger (e.g., fear of failing exams, anxiety about their career, wanting to make money).
2.  **Action**: Easy consumption of the video (clean typography, fast pace).
3.  **Variable Reward**: The value payout. Solve the open loop. Give them a "lightbulb" moment (e.g. explaining a complex term like *JSON* in 10 seconds).
4.  **Investment**: A prompt to action at the end. Make them comment, share, or join the waitlist.
